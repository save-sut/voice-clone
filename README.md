# voice-clone — โคลนเสียงตัวเองด้วย VoxCPM2

ใช้ฟรีและรันในเครื่องทั้งหมด (Apple Silicon / MPS) ไม่ส่งเสียงขึ้น cloud
โมเดล [VoxCPM2](https://github.com/OpenBMB/VoxCPM) ใช้สัญญาอนุญาต Apache-2.0 จึงใช้เชิงพาณิชย์ได้ รองรับภาษาไทย
ไฟล์โมเดลประมาณ 4–5 GB เก็บอยู่ที่ `~/.cache/huggingface/hub/models--openbmb--VoxCPM2`

## ติดตั้ง (ครั้งแรก หรือหลัง clone repo นี้)

ต้องมี [uv](https://docs.astral.sh/uv/) และ ffmpeg (`brew install ffmpeg`)
```bash
git clone https://github.com/OpenBMB/VoxCPM.git           # ทดสอบแล้วกับ commit f0c787f
uv venv --python 3.12 .venv                               # VoxCPM รองรับ Python < 3.13
SETUPTOOLS_SCM_PRETEND_VERSION=2.0.0 uv pip install --python .venv/bin/python -e ./VoxCPM sounddevice
```
ครั้งแรกที่รัน `clone.py` จะโหลดโมเดลเอง (4.6 GB)
ไฟล์เสียงใน `refs/` และ `out/` ไม่ได้อยู่ใน git เพราะเอาไปโคลนเสียงได้ ต้องสำรองไฟล์เหล่านี้เอง

## ขั้นตอน

**1. อัดเสียงต้นแบบ** (ประโยคอยู่ใน `sentences.md`)
```bash
bash record.sh --list          # ดูรายชื่อไมค์ (ค่าเริ่มต้นคือ "MacBook Pro Microphone")
bash record.sh --test          # วัดเสียงรบกวนในห้องและระดับเสียงพูดก่อนอัดจริง
bash record.sh 11-story-home   # กด Enter เพื่อเริ่ม พูดจบแล้วกด Enter อีกครั้ง
MIC="ชื่อไมค์" bash record.sh 02-explain
```
จะได้ไฟล์ `refs/<ชื่อ>.wav` และ `refs/<ชื่อ>.txt` ถ้าพูดไม่ตรงประโยคทุกคำ ให้แก้ `.txt` ให้ตรงกับที่พูดจริง
ครั้งแรก macOS จะถามสิทธิ์ไมโครโฟนให้แอป Terminal/VS Code ให้กดอนุญาต

**2. สร้างเสียงจากข้อความ**
```bash
.venv/bin/python clone.py --text "สวัสดีครับ ยินดีที่ได้รู้จัก"
.venv/bin/python clone.py --file บท.txt --takes 3        # บรรทัดละ 1–2 ประโยค
```
ค่าเริ่มต้นได้มาจากการฟังเทียบ: ต้นแบบ `13-chat-friend`, 25 steps, cfg 2.0 กับบรรทัดที่มีคำอังกฤษ และ 1.5 กับบรรทัดไทยล้วน
เปลี่ยนต้นแบบได้ด้วย `--ref` และบังคับค่า cfg ทุกบรรทัดได้ด้วย `--cfg`
คำอังกฤษจะเขียนเป็นตัวอังกฤษ ("file") หรือคำอ่านไทย ("ไฟล์") ก็ได้ ฟังแล้วชัดพอ ๆ กัน
ผลลัพธ์อยู่ที่ `out/` เปิดฟังด้วย `afplay out/<ไฟล์>.wav`

**หรือใช้หน้าเว็บ** (มีปุ่มอัดเสียงและถอดข้อความต้นแบบให้อัตโนมัติ)
```bash
cd VoxCPM && ../.venv/bin/python app.py --port 8808 --device auto
# เปิดเบราว์เซอร์ไปที่ http://localhost:8808
```

## ปรับให้เป็นธรรมชาติขึ้น

| อาการ | ลองแก้ |
|---|---|
| ไม่ค่อยเหมือนเสียงเรา | อัดต้นแบบใหม่ในห้องที่เงียบกว่า, เช็กว่า `.txt` ตรงกับที่พูดทุกคำ, ลองไฟล์ต้นแบบอื่น |
| น้ำเสียงหรืออารมณ์ไม่ตรงงาน | เลือกต้นแบบที่อารมณ์ตรงกับงาน (คุยสบาย ๆ / นำเสนอ / เล่าเรื่อง) |
| เสียงแข็ง ฟังเหมือนหุ่นยนต์ | ลด `--cfg` เช่น 1.5 |
| เพี้ยนจากเสียงต้นแบบ | เพิ่ม `--cfg` เช่น 2.5 |
| เสียงไม่ละเอียด มีเสียงแตก | เพิ่ม `--steps` เช่น 20 (จะช้าลง) |
| ข้อความยาวแล้วเพี้ยนหรือข้ามคำ | แยกบรรทัดละ 1–2 ประโยค |
| อ่านคำอังกฤษหรือตัวเลขผิด | เขียนเป็นคำอ่านแทน เช่น "บ่ายสอง" แทน "14:00" |
| บางรอบดี บางรอบไม่ดี | ใช้ `--takes 3` แล้วเลือกรอบที่ดีที่สุด |

## สถานะล่าสุด (2026-10-07)

- **ต้นแบบที่ดีที่สุดตอนนี้: `13-chat-friend`** เสียงเหมือนแล้ว แต่น้ำเสียงยังเหมือนอ่านหนังสือ เพราะตอนอัดอ่านจากบท
- โหมด Controllable (`--no-prompt --style "..."`) ได้อารมณ์สนุก แต่เสียงไม่ค่อยเหมือน
- ไฟล์ชุดแรก (`refs/v1/`) อัดตอนที่ ffmpeg ยังทำเสียงหลุด ตอนนี้เปลี่ยนไปอัดด้วย `rec.py` แล้ว
- **ขั้นต่อไป:** อัดชุดที่ 3 แบบพูดสด (`21-free-excited`, `22-free-funny`, `23-free-hype` ดูใน `sentences.md`) แล้วพิมพ์ข้อความที่พูดลง `.txt`
  จากนั้นสร้างเสียงเทียบ: `.venv/bin/python clone.py --ref 21-free-excited --file fun-text.txt`
- ถ้ายังไม่พอ: ทำ LoRA fine-tune ด้วยเสียงตัวเอง 5–10 นาที (`VoxCPM/lora_ft_webui.py`) ยังไม่ได้ทดสอบว่า train บน Mac ไหว
